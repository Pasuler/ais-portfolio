# Ais Hidayatul Uyun — Professional Portfolio

Static portfolio for a Biology graduate focused on applied microbiology, food quality control, and veterinary diagnostics.

## Stack

- HTML5, CSS3, vanilla JavaScript
- GitHub Pages
- WebP image assets
- No build framework or backend

## Local preview

From the project root:

```sh
python -m http.server 8099 --bind 127.0.0.1
```

Open `http://127.0.0.1:8099/`.

## Pages

- `index.html` — profile, skills, projects, experience, certificates, contact
- `project-tape.html` — tape ketan BAL research and source dataset
- `project-enkapsulasi.html` — probiotic encapsulation research
- `project-diagnostik.html` — BBVet Wates laboratory practice
- `project-airmawar.html` — alcohol-free rose-water product project

## Deployment

Publish repository root with GitHub Pages. Relative paths are used for project assets.

## Content accuracy

Project narratives are based on materials supplied by the portfolio owner. Verify any result, protocol, numerical interpretation, or professional claim against the original report before public release. No CV PDF is bundled because the supplied portfolio PDF may need factual review first.

## Boundaries

Do not commit `.env`, credentials, session files, private keys, or personal data unrelated to the portfolio. Source images remain in the original Downloads folder; only optimized selected WebP images are included here.
